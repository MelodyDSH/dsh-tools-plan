# 快速上手

> 整套约 15 分钟，其中 10 分钟是第一次装 Python。不用懂代码，照顺序做即可。
> 每一步都写了「**这里该看到什么**」，对不上就停在原地查，别往下走。

---

## 先花 10 秒想清楚你要哪种

| 你想干什么 | 走哪几步 |
|:---|:---|
| 直播 / 录屏时画面里显示心跳（OBS） | 1 → 2 → 3 → 4 → 5 → **6** |
| 桌面上挂个置顶小心率窗 | 1 → 2 → 3 → 4 → **7** |
| 手环还没到，只想看看长什么样 | 1 → 2 → **0.5（演示模式）** |

---

## 0.5 没有手环也能先看界面（可选，1 分钟）

先装一次依赖（只需一次），再跑演示模式：

```bat
pip install -r requirements.txt
python hr_service.py --demo
```

然后浏览器打开 <http://127.0.0.1:8787/skin/gauge>。

**这里该看到**：一个黑色六边形中控台，心率数字在跳（`DEMO BAND`，假数据）。
看完 `Ctrl+C` 停掉，再按下面正常流程走。

---

## 1. 装 Python（10 分钟，只做一次）

1. 打开 <https://www.python.org/downloads/windows/>，下 **Windows installer (64-bit)**，3.11 或 3.12 都行
2. 双击装，**第一屏最下面那个 `Add python.exe to PATH` 一定要勾上**
3. 装完验证：`Win`+`R` → 输入 `cmd` → 回车 → 在黑窗口里打：

```bat
python --version
```

**这里该看到**：`Python 3.12.x`（数字不重要，有 `Python 3.` 就行）。

> 如果提示 `'python' 不是内部或外部命令`：说明第 2 步没勾 PATH。卸载重装，注意勾选。

---

## 2. 下载并解压（1 分钟）

1. 点仓库右上角 **Code → Download ZIP**
2. 解压到一个**自己能找到**的目录，比如：

```
D:\heart-rate-overlay\
```

**这里该看到**：目录里有 `start-service.bat`、`hr_service.py`、`overlay` 文件夹。

> 别解压到 OneDrive / 网盘同步目录里——同步程序会锁住文件，服务起不来。

---

## 3. 手环打开「心率广播」（1 分钟）

小米运动健康 App → 设备 → 你的手环 → 设置 → **Share HR** → 打开。

**这里该看到**：手环屏幕上出现广播中的提示（不同型号样子不同，有的显示一个心形/链接图标）。

> ⚠️ 开了之后手环可能和手机断开，这是正常的——它现在在当"心率带"用。

---

## 4. 启动服务（2 分钟，第一次会装依赖）

**双击 `start-service.bat`。**

它会自动找到 Python、装依赖（第一次 30~60 秒，之后就快了），然后开始扫描手环。

**这里该看到**（黑窗口里的字）：

```
[22:31:02] 心率服务启动 手环: Smart Band 端口: 8787
[22:31:02] 扫描 6.0s 找手环 ...
[22:31:09] 锁定 Xiaomi Smart Band XXXX XXXX AC:XX:XX:XX:XX:XX RSSI=-55 score=178
[22:31:10] 已连接，订阅 0x2A37
[22:31:10] 电量 72%
```

**没看到的对照**：

| 黑窗口里写着 | 意思 | 怎么办 |
|:---|:---|:---|
| 一闪就没了 / 弹一下关闭 | Python 没装好 | 回第 1 步，重开一个 cmd 打 `python --version` 试试 |
| `'python' 不是内部或外部命令` | 没勾 PATH | 重装 Python，勾 `Add python.exe to PATH` |
| `pip` 报错、下载失败 | 网络/代理 | 挂梯子后重开 bat；或手动 `pip install bleak` |
| 一直 `没扫到目标手环` | 手环没开广播 / 太远 / 被手机连着 | 回第 3 步；手环贴近电脑；手机先断开手环 |
| 连上了但数字不动 | 连错设备了 | 等它自己断开重扫（约 25 秒）；或把 MAC 写进 `config.json` |

> **这个黑窗口不能关**，关了服务就停了。想一边用一边干别的，把它最小化。

---

## 5. 先在浏览器里看效果（1 分钟）

三个地址，挨个打开看看：

| 地址 | 是什么 |
|:---|:---|
| <http://127.0.0.1:8787/skin/gauge> | 皮肤「赛博仪表盘」（推荐） |
| <http://127.0.0.1:8787/overlay> | DIY 浮层（自己调的那套） |
| <http://127.0.0.1:8787/editor> | 设置页：拖滑块改外观，改完 OBS 里立刻变 |

**这里该看到**：数字在跳，和你的心跳对得上（坐着不动一般 60~75）。

---

## 6. 接进 OBS（3 分钟）

1. OBS 底部「来源」→ 点 `+` → 选 **浏览器**
2. 名字随便写（比如"心率"）→ 确定
3. 在属性里填：

| 项目 | 填什么 |
|:---|:---|
| URL | `http://127.0.0.1:8787/skin/gauge`（或 `/overlay`） |
| 宽度 | `1100`（用 `/overlay` 就填 `900`） |
| 高度 | `520`（用 `/overlay` 就填 `300`） |
| 「关闭源时关闭页面」 | 不用勾 |
| 自定义 CSS | 留空 |

4. 确定，然后把这个源拖到你想放的位置

**这里该看到**：画面里出现中控台，背景是透明的（不是黑块）。

**看不到 / 一片黑**：

- 右键这个源 → **刷新页面**（最常见的就是这个）
- 确认第 4 步的黑窗口还开着（关了就没数据）
- 地址少写了 `/skin/gauge` 或 `/overlay` 也会黑

---

## 7. 桌面置顶小窗（可选，1 分钟）

**双击 `start-window.bat`**（服务要开着）。

**这里该看到**：屏幕角落一个无边框小心率窗。

- 左键拖着移动
- 右键出菜单（置顶 / 关闭）
- `Esc` 退出

---

## 8. 想开机自动跑（可选）

1. `Win`+`R` → 输入 `shell:startup` → 回车，会打开「启动」文件夹
2. 右键 `start-service.bat` → 创建快捷方式 → 把快捷方式拖进这个文件夹

> 副作用：每次开机都会弹一个黑窗口。

---

## 9. 不想要了怎么清干净

1. 关掉黑窗口 = 服务停止
2. 直接删掉整个文件夹就行——它**不写注册表、不装服务**，只会在这两个地方留东西：
   - 文件夹里的 `config.json`（你的设置）
   - 文件夹里的 `assets\`（你上传的图标/底图）

---
