# 心率直播组件 · 方法说明

一句话：**一个后台服务收手环心率 → OBS 用「浏览器源」显示 → 另有一个桌面小窗**。

## 文件清单

| 文件 | 干什么 |
|:---|:---|
| `start-service.bat` | 双击启动后台服务（黑窗口，别关）。端口 `127.0.0.1:8787` |
| `open-settings.bat` | 双击打开**可视化设置页**（改颜色/图标/字号，即时生效） |
| `start-window.bat` | 双击打开桌面悬浮心率小窗（要先开服务） |
| `hr_service.py` | 服务本体：锁手环、收 0x2A37、对外提供网页/JSON/SSE |
| `hr_window.py` | 桌面小窗（读服务接口，不碰蓝牙） |
| `overlay/index.html` | OBS 浏览器源显示的页面 |
| `overlay/editor.html` | 可视化设置页（浏览器打开，左侧调、右侧预览） |
| `config.json` | 手环 MAC、RSSI 下限、心率分档颜色和 GIF |
| `ble_hr.py` | 命令行调试工具（scan / watch），排障用 |
| `assets/` | 放你自己的 GIF/图片，被 `/asset/文件名` 直接引用 |

## 三分钟用起来

1. 手环上：设置 → **Share HR** → 打开（屏幕亮着时开启）
2. 双击 `start-service.bat`，看到 `已连接，订阅 0x2A37` 就对了
3. OBS → 来源 → `+` → **浏览器** → URL 填
   `http://127.0.0.1:8787/overlay`，宽 `460` 高 `220`
   （右键源 → 变换 → 适应屏幕，再自己拉大小）
4. 想要桌面小窗：双击 `start-window.bat`，左键拖动，右键菜单可关

OBS 浏览器源默认就是透明背景，不用额外设置；不要勾"通过 CSS 自定义"。

## 可视化设置（推荐用这个，不用手改 config）

双击 `open-settings.bat`，或浏览器打开 `http://127.0.0.1:8787/editor`。

| 能调什么 | 说明 |
|:---|:---|
| 图标 | 下拉选 `assets\` 里的图，留空 = 默认心形；旁边「上传…」直接传新图 |
| 图标尺寸 / 间距 / 字号 / 圆角 / 不透明度 | 拖滑块，右侧预览立刻变（圆角 0~60，60 = 全圆角，也可以点按钮） |
| 图标 ↔ 数字 间距 | 变大时**卡片右缘钉住不动**（往左让一半），右边那块不会跟着抖 |
| 位置微调（左右 / 上下）+ 一键复位 | 只在框内挪图标和数字，不推挤右侧；「一键复位」把偏移、两处间距全部归位 |
| 卡片样式 | 「显示玻璃面板」「显示描边和投影」两个开关，全关就是纯图标 + 数字 |
| 背景图 + 不透明度 | 全局底图 |
| 字体 | **下拉选本机已装字体**（读系统字体列表） |
| 右侧工作区 | 4 个开关按钮：单位 BPM / 档位名 / 设备信息 / 电量，点了开才显示；各自有字号 |
| 设备名 | 可以自定义（留空就用手环真名） |
| 电量显示 | 圆环 / 电池条；数字可选「画在环心 / 放右边 / 不显示」；调图标大小数字自动跟着缩放 |
| 每档 名字 / 颜色 / 图标 / 区间 | 分档换的是**图标**和颜色，不再绑背景 |
| 素材管理 | 每张图后面有「删除」，删掉的图如果还被引用会自动清空引用 |

右侧那四个开关怎么排：**开几项都自动等距居中**——2 项时上下对称，3 项时中间那项在正中，
图标和文字的中线始终在一条横线上。「这几项之间的间距」滑块控制紧凑还是松散。

改完 **160 毫秒自动保存**，服务会 `theme.rev += 1` 并把新配置通过 SSE 推给 OBS，
**OBS 里不用刷新**（图片按 `?v=rev` 破缓存，换图也立即生效）。
设置存在 `config.json` 的 `theme` 块里；想恢复默认就把 `theme` 删掉重启服务。

接口（想脚本化就用这些）：

| 接口 | 方法 | 说明 |
|:---|:---|:---|
| `/api/config` | GET | 读全量配置 |
| `/api/config` | POST | 部分合并（给多少改多少），自动存盘 + 推送 |
| `/api/assets` | GET | 列出 `assets\` 文件名 + 字节数 |
| `/api/asset?name=x.gif` | POST | 上传素材（只收 png/jpg/gif/webp） |
| `/api/asset?name=x.gif` | DELETE | 删素材，顺带清掉 theme/zones 里对它的引用 |
| `/api/fonts` | GET | 本机字体家族列表 |

## 皮肤（整套外观，不做 DIY 混搭）

设置页顶部两个页签：**DIY 调整**（上面那一整套滑块）和 **皮肤**。

皮肤是独立页面，跟 DIY 那套互不干扰；OBS 里换个源地址就能用：

| 皮肤 | OBS 地址 | 长什么样 |
|:---|:---|:---|
| 赛博仪表盘 | `http://127.0.0.1:8787/skin/gauge` | 宽六边形中控台：左心率圆盘 / 中间信息块 / 右电量圆盘，各有指针 + 环形能量条 |

- 加 `?still=1` 关掉全部动效（撕裂抖动、扫描光带、跑马灯、数字闪帧）：`/skin/gauge?still=1`
- 中间信息块（`overlay\skins\gauge.html` 的 `.info`）现在显示 DEV / BATT / RSSI / SAMP / LINK，
  底下 `#sparkPath` 是最近 40 次心率的折线，颜色跟随档位；以后要加东西就长在这里

赛博仪表盘的档位（颜色同时作用于能量条、指针、数字）：

| 档 | 心率 | 颜色 | 名字 |
|:---|:---|:---|:---|
| 1 | 0–9 | 灰 `#8b93a1` | 休眠 |
| 2 | 10–20 | 绿 `#2bff88` | 静默 |
| 3 | 21–40 | 蓝 `#2ea8ff` | 平稳 |
| 4 | 41–60 | 紫 `#a45bff` | 专注 |
| 5 | 61–80 | 黄 `#ffd60a` | 热身 |
| 6 | 81–99 | 橙 `#ff8a1e` | 燃脂 |
| 7 | 100+ | 红 `#ff2b4e` | 极限 |

电量盘按健康度分 5 段：<10 红 / <25 橙 / <50 黄 / <75 绿 / 其余青。
改档位或颜色，直接编辑 `overlay\skins\gauge.html` 顶部的 `HR_ZONES` 数组就行。

想加自己的皮肤：把 `xxx.html` 丢进 `overlay\skins\`，它会自动出现在「皮肤」页签里。
皮肤页面自己读 `/api/hr` 和 `/events`，可以用 `?t=` 之类参数破缓存，也可以直接写死自己的颜色。

## 换图 / 换 GIF

1. 把 `xxx.gif` 丢进 `assets\`（或在设置页「上传…」）
2. 设置页 →「心率分档」→ 对应档位的图标下拉里选它（分档换图标）
3. 想整块背景换图：设置页「底图 / 背景」下拉选
4. 想全局固定一张图、不分档：URL 后面加 `?gif=bg.gif`
5. 想要长条模式（直播下方信息条）：URL 加 `?mode=bar`

分档规则按左闭右开 `min <= bpm < max`，颜色就是数字、心形和档位名的颜色。

## 电量怎么来的

连上手环后读标准电量特征 `0x2A19`（Battery Level），之后每 5 分钟刷一次。
手环不暴露这个特征就读不到（界面自动隐藏电量那一块，不会显示假数）。
小米手环的准确电量走私有协议 `0xFE95` + auth key，那条路没做。

## 设备锁定（抗干扰）

`config.json` 里 `device.mac` 是唯一身份，打分规则在 `hr_service.py` 的 `pick_device()`：

| 条件 | 加分 |
|:---|:---|
| MAC 完全一致 | +100 |
| 广播里含 `0x180D` 心率服务 | +50 |
| 名字含 `Smart Band` | +40 |
| RSSI 低于 `min_rssi`（默认 -85） | -60 |

- 分数必须 ≥50 才连，**打平且信号接近就拒绝连接**（宁可无信号，不串台）
- 场上同时出现多台 0x180D 设备会在日志里点名警告
- 连上后 **25 秒没有心率** → 判定连错，自动断开重扫
- 断线自动重连，退避 1→2→4→8→15→30 秒

## 常见问题

| 现象 | 原因 | 怎么办 |
|:---|:---|:---|
| 日志一直「没扫到目标手环」 | Share HR 停了（离手/息屏/超时） | 手环上重新开 Share HR |
| 扫到了但连不上 | 手机 App 正占着手环 | 手机蓝牙关一会儿，或关掉小米运动健康 |
| 小窗显示「服务没开？」 | 服务没启动/端口被占 | 看黑窗口有没有报错，`netstat -ano | findstr 8787` |
| OBS 里一片透明/空白 | URL 写错或服务没开 | 浏览器打开 `http://127.0.0.1:8787/api/hr` 看有没有 JSON |
| 心率几秒才变一次 | 手环本身的广播节奏（约 1~2 秒一条） | 正常，改不了 |
| 设置页改了图标/背景没反应 | 改完页面缓存了旧的浮层 | 点设置页的「重新载入」（会顺带刷新预览），或 Ctrl+F5 |
| 上传了图但浮层还是心形 | 图片名带中文以前会 404（已修） | 现在支持中文文件名；仍不行就换成纯英文名再试 |

## 已知边界

- 手环广播间隔 0.8~2.1 秒，做心跳动画时会显得有点"顿"，这是数据源上限
- 这台手环不广播 RR 间期，所以没有逐拍心率
- 服务和小窗都是本机回环，不联网、不外发

## 赛博仪表盘皮肤怎么改（`overlay\skins\gauge.html`）

结构是三层：`.shell`（`inline-flex` 竖排，**必须是 inline-flex**）= 顶栏 `.cs-top` → 六边形 `.console`（里面只有 `.stage`）→ 底栏 `.cs-bot` → 跑马灯 `.ticker`。
**六边形只包表盘**，所以"太长 / 太空 / 角凸出来"改的是下面这几个值：

| 想改什么 | 改哪儿 | 现在 |
|:---|:---|:---|
| 两侧三角尖多深 | `:root` 的 `--nose` | `34px` |
| 表盘左右离框多远 | `:root` 的 `--pad-x`（同时是 `.console` 的左右 padding） | `38px` |
| 框上下贴不贴 | `.console` 的 `padding` 第一段 | `6px` |
| 表盘多大 | `.gauge` 的 `width` | `clamp(196px, 19vw, 296px)` |
| 三块之间多挤 | `.stage` 的 `gap` | `clamp(8px, .9vw, 14px)` |
| 中间信息块多宽 | `.info` 的 `min-width` | `clamp(112px, 11.5vw, 152px)` |

- `--hex` 里用 `var(--nose)` 算顶点（`polygon(0% 50%, var(--nose) 0, calc(100% - var(--nose)) 0, 100% 50%, …)`），
  **铆钉 `.bolts b` 的坐标也引用 `--nose`**，改尖深就一起跟着走
- ⚠️ `.shell` 如果换回 `display:flex`，底部跑马灯那行 `nowrap` 长文字会把整个壳撑到全屏宽，
  六边形就变成"贴着窗口边"，尖角和内边距全部失效（2026-11-08 踩过，症状是上下两条霓虹线横穿屏幕、顶栏文字跑到框外）
- 单位文字（BPM / BATTERY %）用 `textLength` 固定宽度居中；**别再回到 `letter-spacing` 居中**，末尾会多半个字距、越长越偏
- 中间信息块里 `#sparkPath` 是最近 40 次心率折线，`margin-top: auto` 把它压到底部
- 动画太多卡机器时，URL 加 `?still=1` 全关


## 十一、预览效果开关（设置台右上角，假心率/假电量/假时长）

手环不在身边时，不用另一个页面，直接在设置台里看：

- 双击 `open-settings.bat` → 右上角状态栏点「预览假数据」
- 打开后：心率在 78±26 之间波动、电量 6 档循环（100/80/60/40/20/8，每 6 秒一档），15 分钟后自动关
- 按钮变绿显示「预览中 · N 分」，再点一次立即关
- 假数据只活在服务内存里：**不写 `config.json`、不改主题**

接口（脚本也能用）：

| 方法 | 路径 | 说明 |
|:---|:---|:---|
| GET | `/api/preview` | 查状态 `{on, mode, batt, left}` |
| POST | `/api/preview` | `{"on":true,"mode":"sweep","batt":42,"minutes":15}` 开；`{"on":false}` 关 |

`mode` 三种：`sweep` 每 6 秒跳一档 / `fixed` 固定 `batt` / `auto` 每 20 秒 -1（从 76% 往下，跌到 8% 回 76）。

注意：

- 预览期间 OBS 里那个源也会显示假数据（大家读同一份快照），**直播前记得点掉**
- 改完代码要**重启心率服务**（关掉 `start-service.bat` 的黑窗口再双击），旧进程里没有这个接口
- 到时间自动关是防忘，不是省电；关掉后立刻回到真实数据（没连手环就是 `--`）

### 11.2 分档灯带（2026-11-08）

仪表盘外圈那七段（心率）/ 五段（电量）是「区间表」不是装饰：

- 值 >= 该段起点 → 该段整段亮（opacity:1、线宽 7.5、带自身颜色发光）
- 还没走到的段保持 opacity:.34 暗着
- 实现：drawZoneRing() 返回 path 数组（带 data-from），
ender() 每帧调 paintZoneRing(paths, value)；无数据传 
ull 全暗
- 改档位颜色只动 drawZoneRing('hrZones', [...]) / ('btZones', [...]) 里的三元组 [起, 止, 颜色]
- **改完 HTML 要刷新页面才生效**（页面只轮询 /api/hr，不重载脚本）

### 11.3 涟漪随心率（2026-11-08）

心跳涟漪（#hrPing）的动画时长不写死，按心率细分，上下限固定 **1.9s ~ 0.36s**：

`js
var t   = Math.max(0, Math.min(1, (bpm - 50) / 90));  // 50~140 bpm 铺满 0~1
var dur = 1.9 * Math.pow(0.36 / 1.9, t);              // 指数映射，越小越快
`

- 为什么用指数：线性映射在 60~100 这段几乎看不出差别；指数把日常区间拉开
- 参考：50→1.90s、70→1.31s、78→1.13s、101→0.74s、120→0.52s、140→0.36s（再快压下限）
- 代价：**不再严格等于心动周期**（101 bpm 真实周期 0.59s，涟漪 0.74s），是「手感」优先于「物理准确」
- 想严格跟拍就把 dur 换成 `Math.max(0.36, Math.min(1.9, 60 / bpm * 0.92))`
- 主浮层 index.html 的心形脉动走的是另一套（--beat = 真实周期），两边故意不同

## 12. 三盘皮肤 gauge3 + 游戏时长（2026-11-08）

### 12.1 皮肤

overlay\skins\gauge3.html，横排左大右两小：

- 左：心率大盘（七档灯带 + 指针 + 数字 + 心跳涟漪）

- 右下：游戏时长小盘（指针 + h:mm 数字，环按「满格小时数」折算）

### 12.2 游戏计时怎么算

**不自己累加，问系统「这个进程什么时候起来的」**，
ow - 创建时间 就是已运行时长：

- game_watch.py：CreateToolhelp32Snapshot 枚举进程 + OpenProcess/GetProcessTimes 取创建时间，纯 ctypes，不依赖 psutil、不起子进程
- 好处：服务重启、切后台、双开都不影响；坏处：游戏进程常驻就一直算
- 进程名大小写不敏感；同名多个取**启动最早**的那个（双开算总时长）
- 进程列表有 2 秒缓存，/api/processes 强制刷新

### 12.5 已知限制（重要）

**沙箱里起的服务只能看到自己那 20 来个进程**，看不到用户的游戏。
必须是**双击 start-service.bat** 起来的服务才看得全（实测沙箱内 24 个 vs 正常几百个）。
